## 🎯 Приоритеты (что делать в первую очередь)

### 🔴 КРИТИЧНО (сделать сегодня)

```bash
# 1. Установить зависимости
npm install

# 2. Проверить форматирование
npm run prettier:check
npm run prettier:fix
```

**Исправить в файлах:**

- `docusaurus.config.js` → изменить tagline
- `.markdownlint.json` → добавить ts, tsx, jsx, css
- `.gitignore` → добавить IDE файлы
- Создать `static/robots.txt`

### 🟠 ВАЖНО (на этой неделе)

1. **Настроить CI/CD**
   - Создать `.github/workflows/ci.yml`
   - Добавить проверки форматирования
   - Настроить автодеплой

2. **Настроить Dependabot**
   - Создать `.github/dependabot.yml`
   - Включить автообновления

3. **Рефакторинг**
   - Вынести данные навигации в отдельный файл
   - Удалить неиспользуемые компоненты

### 🟡 ЖЕЛАТЕЛЬНО (в течение месяца)

4. Оптимизировать изображения (WebP, сжатие)
5. Добавить SEO метатеги (Open Graph, Twitter)
6. Настроить тестирование (Vitest)
7. Добавить анализ бандла
