# Анализ проекта Knowledge Bank

**Название проекта:** Knowledge Bank (Банк знаний)  
**Назначение:** Личная база знаний по веб-разработке, дизайну, созданию контента  
**Тип проекта:** Статический сайт документации

## 📝 Примеры кода из проекта

### Пример markdown с кастомными компонентами

Согласно README.md, в проекте используются кастомные React компоненты внутри markdown:

```markdown
export const MARK = ({children}) => (
  <mark style={{ backgroundColor: 'maroon', color: 'white' }}>
    {children}
  </mark>
);

## <MARK>Some title</MARK>
```

### Структура документа

Все markdown документы следуют единому формату:

```markdown
---
title: Название раздела
sidebar_position: 0
---

## Заголовок

Содержание с кодом, изображениями и ссылками...
```
